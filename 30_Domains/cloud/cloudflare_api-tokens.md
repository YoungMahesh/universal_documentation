### create api token to manage 'Cloudflare Pages'

1. Visit 'https://dash.cloudflare.com/profile/api-tokens'
2. Click 'Create Token'
3. In 'Policies' section, click 'Start from Scratch'
4. Click 'Start with an Account Policy'
5. In 'Edit Account Policy' searchbox, search 'Pages'
   - Go to 'Developer Platform' section -> 'Cloudflare Pages' row -> Check 'Read' and 'Edit'
6. In 'Token Expiration' section select Token Expiry duration
7. Click 'Continue to Summary' at bottom
8. Click 'Create Token'
